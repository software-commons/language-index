# Python qualification pilot

Candidate `0.1.0-rc.1` covers one language identity and one documented name-resolution rule in the Python 3.13.0 Language Reference. The broader census and its predecessor matches remain discovery leads. Other Python editions, design facets, historical claims, and implementation relationships remain outside this selection.

- [Python identity, revision 2](../../sces/records/claim/python-313-language-identity--2.json) separates the language from CPython and identifies `active` as the state of this index record. Upstream version, branch maintenance, and implementation classifications have their own boundaries.
- [Unbound function-local name, revision 2](../../sces/records/claim/python-313-unbound-function-local--2.json) concerns a read of a name classified as local to the current function before it is bound there. Global, free-variable, annotation-scope, and class-scope resolution are outside the condition.
- [Nearest `nonlocal` binding](../../sces/records/claim/python-313-nonlocal-nearest-binding--1.json) remains excluded. Independent review found the frozen applicability condition too broad. In a nested function, an intervening `global` declaration can make an outer textual binding unavailable and produce `SyntaxError`. A subsequent revision needs an eligible, lexically visible binding condition and fresh verification. [Independent assessment](../../sces/records/verification/python-pilot-review-python-313-nonlocal-nearest-binding-r1--1.json)

The first pilot pass found that the provisional Python subject contained 33 hexadecimal digits. Domain validation requires 32. The two selected claims use new immutable revisions with a valid subject. Separate Codex executions reacquired and independently inspected both controlling documents after the correction, and the resulting digests matched the registered sources. The `nonlocal` assessment retains its original claim and separate traces. The initial challenge used CPython 3.13.5 for locally authored comparisons and inspected the pinned CPython 3.13.0 compiler for the intervening-`global` case. The Language Reference controls the documented propositions.

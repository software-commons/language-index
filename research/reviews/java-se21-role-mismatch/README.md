# Java SE 21 identity evidence role

The first candidate build rejected the exact revision 1 identity binding. The selected category, `documented`, requires an official-documentation source record under SCES-1.0. The captured Java Language Specification chapter was registered as a governing specification. The second build rejected the `descriptive` category for revision 2 because the Language Index limits its `identity-boundary` predicate to documented, historical, or derived claims.

This directory preserves both unadmitted claim revisions, their attempted bindings and assessments, and the second acquisition pair. The active registry uses a new independently reviewed claim that records the publisher's exact opening paragraph as documentation of the Java identity in this edition. The registry keeps the Java entity's permanent identity. See the [profile evidence](../../campaigns/java-se21-profile.md).

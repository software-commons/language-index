# Standard ML ’97 and OCaml 5.3

The selected Standard ML claims use the revised 1997 language definition. They cover nested comments, limits on value binding generalization, propagation past an unmatched exception handler, and core application evaluation order. The selected OCaml claims use the project’s 5.3 reference for or-pattern bindings, unspecified application order, false guard continuation, and module type constraints. Each technical conclusion retains its own specification and edition scope.

The [Standard ML classifier](https://github.com/github-linguist/linguist/blob/cfd7a0113aa1efab99faeff38756f0ed4d48add8/lib/linguist/languages.yml#L7879) resolves to the language identity. The five complete pinned specimens include separate sources that use implementation libraries. The classifier does not establish an edition or the runtime behavior of those libraries.

The [OCaml classifier](https://github.com/github-linguist/linguist/blob/cfd7a0113aa1efab99faeff38756f0ed4d48add8/lib/linguist/languages.yml#L5534) has a supported association with ordinary OCaml source and interfaces. It also includes legacy Eliom forms and tooling scopes for lexer and parser descriptions. The complete pinned classifier remains unresolved.

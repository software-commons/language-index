# Mesa and Xerox PARC MPL

The Mesa profile uses the April 1979 Version 5.0 language manual for the base identity and exact documented interface, module, and process claims. The December 1976 system documentation records the initial Alto distribution. A distinct November 2 language manual addendum describes a planned compiler transfer and flags divergence from the then-current language and grammar. The aggregate Mesa 1.0 lead remains unresolved across these documentary and distribution scopes. [Mesa Language Manual 5.0](https://www.bitsavers.org/pdf/xerox/mesa/5.0_1979/documentation/CSL_79-3_Mesa_Language_Manual_Version_5.0_Apr79.pdf) · [Initial Alto system documentation](https://softwarepreservation.computerhistory.org/mesa/doc/parc/Mesa_1.0_Dec76.pdf)

The February 1974 MPL(B) document identifies the Xerox PARC MPL language line. It describes limited extensions of MPL(A) and separately records an intent to maintain compatibility with subsequent MPL versions. The exact MPL catalog heading remains unresolved across different language versions, runtime material, and MPS records. The catalog’s cross-reference for the compatibility discussion points to the debugger entry. The contemporary language document supplies the directly inspected statement of intent. [MPL(B) reference](https://softwarepreservation.computerhistory.org/mesa/doc/m0671/M0671_b6_f2-Satterthwaite-DOCMPS%2CMPL-B.NLS-1974_02_25.pdf) · [CHM Mesa collection](https://softwarepreservation.computerhistory.org/mesa/) · [Lead decisions](../../sces/artifacts/mesa-archive-origin-review.json) · [Independent source witnesses](../../sces/artifacts/mesa-archive-source-witnesses.json)

The first Mesa release-target claim revision attributed to the addendum an intent to describe the compiler. A separate reading found that the addendum identifies the expected language at the planned compiler transfer as the manual’s subject. The later adverse assessment invalidates the exact first revision. [Adverse source witnesses](../../sces/artifacts/mesa-target-adverse-source-witnesses.json)

# KuMir and Pikto

The KuMir profile uses the project's tagged 2.1.0 rc11 documentation for the classic language. Its four technical claims cover the documented program structure, commands and control flow within that edition. [Source witnesses](../../sces/artifacts/kumir-piktomir-source-witnesses.json)

The Pikto profile uses the 2023 journal article and the authors' 2019 conference slides as separate historical witnesses. Its technical claims preserve the source-specific scope and distinguish Pikto programs from the environments that host them. [2023 journal article](https://doi.org/10.1134/S1995080223010103)

Two earlier leads cite whole issues of the NIISI journal. Separate executions could not obtain the original documents because both certificate checks failed. Both leads remain unresolved. [Lead decisions](../../sces/artifacts/kumir-piktomir-origin-review.json)

# Smalltalk-80 language design

The profile uses Goldberg and Robson’s 1983 Blue Book at the already registered exact source revision. Its language claims cover named instance and class state, ordinary and `super` message lookup, method argument and temporary bindings, return values, and the arity of parameterized blocks. The claims record the book’s exact class and expression contexts. System class-library behavior, virtual-machine implementation, and later Smalltalk dialects require separate evidence.

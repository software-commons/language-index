# Configuration notation boundaries

Eight scoped notation records describe Cylc workflow configuration, EditorConfig, Git configuration, npmrc, Readline inputrc, Wget startup files, Desktop Entry, and nanorc. Each has its own supporting authority and documented declaration or expression model. The pinned Linguist catalog groups these forms for classification. The individual authorities establish their applicable syntax and scope. [Independent source witnesses](../../sces/artifacts/ini-classifier-scope-source-witnesses.json)

Six of the ten leads support scoped links. The Git Config, SSH Config, cURL Config, and desktop entries remain open at whole-entry scope. The samples expose overlapping selectors, daemon-named files with client directives, and template suffixes. The independently supported Git configuration and Desktop Entry identities retain the narrower boundaries in their publisher sources.

# XQuery 3.1 and XSLT 3.0

The XQuery profile uses the W3C Recommendation dated March 21, 2017. It records the item and sequence model, the two array constructor forms, and the defined choices for static typing, library module support, and serialization. The XSLT profile uses the June 8, 2017 Recommendation. It records package composition, its required XPath baseline and optional XPath 3.1 feature, streaming conditions, and the schema-awareness boundary. Processor behavior and other language versions require separate evidence. [XQuery 3.1](https://www.w3.org/TR/2017/REC-xquery-31-20170321/) · [XSLT 3.0](https://www.w3.org/TR/2017/REC-xslt-30-20170608/)

The original XSLT template-focus claim remains in the evidence history with its adverse review. Its broad account of named invocation missed the callee’s explicit `xsl:context-item use="absent"` declaration. The original claim revision is excluded from selection. [XSLT context item declaration](https://www.w3.org/TR/2017/REC-xslt-30-20170608/#element-context-item)

Both publisher origins support their corresponding language identities. The sole pinned XSLT specimen declares version 1.0 and contains XML syntax and embedded XPath selections. Its classifier supports an unversioned XSLT association. The sole pinned XQuery specimen declares version 3.0 and serves an XProc application. The pinned editor grammar delegates a separate JSONiq form. The aggregate XQuery classifier remains unresolved, with a supported ordinary XQuery association.

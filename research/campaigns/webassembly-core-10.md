# WebAssembly Core 1.0

The 2019 W3C announcement supports the core language identity. Six further claims come from the dated Core Specification 1.0 Recommendation and cover binary module structure, text and binary representations of abstract modules, `select`, memory limits, `i32.load`, and `memory.grow`. The binary version field also appears in later core specifications, so the field alone cannot identify the Recommendation edition. Browser and other host APIs, WASI, and WIT have separate scopes.

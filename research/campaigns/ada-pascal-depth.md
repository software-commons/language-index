# Ada 2022 and ISO Pascal profile depth

The Ada findings use the unannotated Ada 2022 Reference Manual. They cover controlled-object operations, completion and finalization, and exact Ada.Exceptions behavior. Specific optimization permissions and edition conditions retain their source scope.

The Pascal findings use the exact unextended ISO/IEC 7185:1990 online replica. The printed version takes precedence where the representations differ. The selected material covers the verified type, pointer and parameter clauses within that version.

The proposed Pascal array claim revision 1 received an adverse independent verdict. The standard’s multi-index example shows that an outer index can select an inner array. The original wording and exact review remain in the evidence history. Revision 2 covers an array type whose written index list specifies exactly one ordinal type. Its component type can itself be an array. Separate research and verification executions examined the single-index clause and the multi-index example. A qualification trial also rejected the original revision when it was added to the selection. No artifact was generated by that trial.

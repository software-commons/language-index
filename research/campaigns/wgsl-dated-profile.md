# WGSL Candidate Recommendation Draft

The W3C publication record identifies WGSL as WebGPU Shading Language and classifies the November 6, 2026 text as a Candidate Recommendation Draft. The identity is scoped to the language. The separate WebGPU API and processor behavior require their own evidence. [Publication record](https://api.w3.org/specifications/WGSL/versions/20261106) · [Dated draft](https://www.w3.org/TR/2026/CRD-WGSL-20261106/)

Seven independently reviewed rules describe this draft's module boundary, nested comments, module-level declaration cycles, evaluation phases, scalar Boolean short-circuiting, atomic modification order, and an executed out-of-bounds access. Each preserves the draft's conditions and distinctions among shader creation, pipeline creation, and execution. [Source witnesses](../../sces/artifacts/wgsl-dated-profile-source-witnesses.json)

The W3C lead resolves to the WGSL language record. The pinned Linguist lead remains open at whole-entry scope. Its sole WGSL specimen contains host-specific import directives. Separate WESL specimens and the shared highlighting grammar inform the classification without establishing a language equivalence.

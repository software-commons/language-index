# Java SE 21 language profile

The Java identity and three technical claims use edition 21 of the Java Language Specification. Sections 1.1, 4.2.5, and 10.2 establish the language's identity, the two values of primitive `boolean`, and the distinction between a created array's fixed length and the array type. A separate Codex execution reacquired all three publisher chapters and reviewed each claim against its exact section and scope. [Introduction](https://docs.oracle.com/javase/specs/jls/se21/html/jls-1.html#jls-1.1) · [Primitive boolean](https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2.5) · [Array variables](https://docs.oracle.com/javase/specs/jls/se21/html/jls-10.html#jls-10.2)

The selected claims apply to the Java language at this specification edition. Java Virtual Machine semantics, boxed `Boolean`, compatibility across editions, and mapping the original regex facility lead to the language identity remain separate research questions.

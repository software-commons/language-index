# Java SE 21 language profile

The Java identity and three technical claims use edition 21 of the Java Language Specification. The introduction identifies the language. Section 4.2.5 specifies the two values of primitive `boolean`. Sections 10.1 and 10.2 distinguish a created array's fixed length from its array type. A separate Codex execution reacquired the publisher chapters and reviewed each technical claim against its exact section and scope. ## Execution and concurrency

A separate Java SE 21 batch covers checked-exception declaration, the first compatible ordinary catch, initialization on reading a nonconstant static field, class initialization in the erroneous state, reverse resource closing, the generated suppression call, and happens-before relationships for monitor locks and volatile fields.

Each claim records the exact construct and applicable condition. Constant variables, abrupt completion, class and loader context, resource initialization, and the identity of the monitor or volatile field affect the bounds. The suppression claim concerns the generated call and retains the possibility that the call itself completes abruptly.

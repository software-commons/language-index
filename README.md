# Language Index

Language Index is Software Commons' evidence-governed reference for software language identities, editions, design, history, and relationships.

- [Scope and identity model](docs/SCOPE.md)
- [Maintenance and offline CLI](docs/MAINTENANCE.md)
- [Publication control](docs/PUBLICATION.md)
- [Population research and coverage methodology](research/campaigns/README.md)

Research and publication follow [SCES-1.0](https://github.com/software-commons/.github/blob/ab26f278422772f2d9e5d4dd016407d14372a710/docs/standards/EVIDENCE_STANDARD.md). This repository contains the registry tooling and research procedures. Each canonical dataset release requires a versioned SCES qualification report.

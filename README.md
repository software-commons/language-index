# Language Index

Language Index is Software Commons' evidence-governed reference for software language identities, editions, design, history, and relationships.

Research and publication follow [SCES-1.0](https://github.com/software-commons/.github/blob/ab26f278422772f2d9e5d4dd016407d14372a710/docs/standards/EVIDENCE_STANDARD.md). This bootstrap establishes the policy and validation path. The repository has no qualified dataset release.

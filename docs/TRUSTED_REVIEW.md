# Trusted Codex technical review

Language Index uses protected pull requests. SCES governs scientific verification of exact claim revisions. The proposed GitHub App requirement governs technical review of the exact integrated change. Publication separately requires authorization of the frozen commit and artifact digests. [Publication control](PUBLICATION.md)

## Issuer and trust boundary

[The issuer patch](../research/review/shared-issuer.patch) adapts the shared License Index issuer at `4b9b8d3ca3056c6fc44cc983af8e941fd3bbc5f0`. Apply it to that exact revision on the independently controlled deployment host. Keep its implementation, configuration, audit records, GitHub credentials, and signing key beyond the reach of pull-request code and the reviewer identity.

Approval has two phases. Queue admission reviews the exact GitHub test merge and publishes a check to the single-parent PR head. That result only admits the PR to the mandatory queue. Final review binds a separate decision to the live singleton merge-group commit. The issuer checks the exact queue ref and ordered base and head parents, verifies genuine successful SCES and Registry runs and job checks on that commit, and rechecks live protection, PR and queue evidence before posting. Retained audit evidence identifies both decisions, reviewed commits, policy artifacts, and source checks. The issuer also captures the SCES tree and exact selected artifact bytes. Changes to workflow, schema, testing, validation or other control paths require separate authorization for the commit reviewed in each phase.

Registry tests run in a separate worker from the required validation job in the proposed Domain workflow. The issuer recognizes the existing combined Registry job and the proposed isolated Registry tests job. Its final gate preserves the two required contexts and their GitHub Actions source, currently App ID `15368`. Checks on the head alone cannot establish the final queue decision.

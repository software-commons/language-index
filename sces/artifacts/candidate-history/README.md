# Historical research candidates

These selectors, qualification reports, and claim payloads preserve the exact draft bytes. The [manifest](manifest.json) records their original Git heads and SHA-256 digests. To reproduce a historical candidate, check out its recorded head and use the pinned SCES policy and the [publication procedure](../../../docs/PUBLICATION.md). The historical selectors retain the original file paths needed by that checkout. Publication requires a separate authorization for the exact assets.
